# Library Management System

## About the Project

This is a basic Library Management System developed using Python as a mini-project. It provides a menu-based approach to managing books, issuing books, and viewing library records.

## Objective

The objective of this project is to understand Python programming concepts by developing a simple application for basic library operations.

## Features

- Admin password verification
- View available books
- Add new books
- Issue books to users
- Return books
- View issued books
- Menu-based program execution

## Technologies Used

- Python
- Jupyter Notebook (.ipynb)

## Python Concepts Used

- Variables and Data Types
- Lists and Dictionaries
- Conditional Statements
- For and While Loops
- User Input
- Functions
- List Operations

## How It Works

The program starts with an admin password check. After successful access, the user can select different menu options to view, add, issue, and return books.

Book details and issue records are maintained using Python lists and dictionaries.

## Project File

`MINI_PROJECT(LibraryManagementSystem)_AshwiniKumarSingh.ipynb`

## How to Run

1. Download the Jupyter Notebook.
2. Open it using Jupyter Notebook or Google Colab.
3. Run the code cells.
4. Follow the instructions displayed in the output.

## Learning Outcome

Through this project, I practised Python fundamentals, functions, data structures, loops, conditional statements, and basic application development.

## Note

This is a beginner-level mini-project. The current version uses in-memory data storage and does not include database integration.
